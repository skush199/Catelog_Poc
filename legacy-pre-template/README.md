# Legacy Pre-Template Reconstruction

This folder contains a standalone reconstruction of the simpler earlier catalog-editing flow from before the larger template workflow expanded.

How to use it:

1. Start the existing API server for this project.
2. Open `http://localhost:3001/legacy-pre-template/`
3. Use the one-page legacy dashboard for:
   - prompt-based catalog editing
   - live print-style preview
   - version review
   - approve and export PDF
   - restoring the original J 300 LM catalog baseline

Notes:

- This legacy reconstruction uses the same API workspace as the current dashboard.
- It is intentionally simpler and does not expose the newer template selection or template creation workflow.
- It is a reconstructed version, not a byte-for-byte recovery of the exact older source state.
